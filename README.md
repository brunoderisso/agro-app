## Descrição

Aplicação frontend, usando React.js, em que trabalhei, cujo propósito é de trabalhar com predições, entre outras funcionalidades (como o uso da API do Google Maps), para fins da agricultura e agro-negócio.
Essa aplicação é muito robusta e grande, com códigos ainda legados, enquanto a maior parte das suas funcionalidades tem qualidade na arquitetura da aplicação, sendo escalável e tendo boa manutenabilidade.
